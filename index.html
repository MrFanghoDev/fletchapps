FletchApps

Les outils numériques des Archers Libres de Fontaine-le-Port pour le chronométrage, la notation et le suivi personnel de tir FFTL / IFAA. Digital tools by Archers Libres de Fontaine-le-Port for FFTL / IFAA timing, scoring and personal shooting logs.

Trois outils, une même flèche Three tools, one arrow

FletchApps régroupe les outils numériques développés en solo pour les Archers Libres de Fontaine-le-Port : un chronomètre de compétition, une application de notation et un carnet de tir personnel, conçus pour les formats FFTL et IFAA. Le code est publié sur GitHub sous licence libre GNU GPLv3, et développé par itérations avec l'assistance d'une IA (Claude, Anthropic) en pair-programming — de l'architecture aux tests — le tout depuis un simple téléphone Android. FletchApps brings together the tools built solo for Archers Libres de Fontaine-le-Port: a competition timer, a scoring application and a personal shooting log, designed for FFTL and IFAA formats. The code is published on GitHub under the free GNU GPLv3 license, and developed iteratively with AI pair-programming assistance (Claude, Anthropic) — from architecture to tests — all from an Android phone.
